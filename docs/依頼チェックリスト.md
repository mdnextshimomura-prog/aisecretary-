# 依頼チェックリスト（初動確認の定義）

**このファイルがAI秘書の「何を聞き返すか」の正本です。**
ここを直すと、LINEで社長へ返す質問の内容が変わります。プログラムの知識は要りません。

編集したら必ず次を実行してください（`src/lib/checklist.generated.ts` が作り直されます）。

```bash
npm run build:checklist
```

`npm run build` にも組み込んであるので、デプロイ時は自動で反映されます。

---

## なぜこれが必要か（トーク履歴 2025.10〜2026.08 の実測）

社長からの指示 **1,133件**（メンション付き）を数えたところ：

| 事実 | 件数 |
|---|---|
| 本文が**12文字以下** | **406件（35%）** |
| 本文が**空**（メンションだけ・添付だけ） | **70件** |
| 「これ」を含む指示 | 236件 |
| Googleマップのリンクのみ／住所のみ | 55件 |

実例：
「陸 これ買いたい」／「𝑌𝑎𝑚𝑎𝑔𝑢𝑐ℎ𝑖 謄本頼む」／「買取と査定 頼む」／
「陸 高槻再販資料ください！」／「舜 調べて」／「ca作って欲しい」／「これ誰か出して欲しい！」

そのため担当者が毎回聞き返しており、**10ヶ月で168件**の確認質問が発生していました。
実際の往復の例：

```
20:10 社長「@小笠原　陸 これ買いたい」＋買付証明書.pdf
20:19 小笠原「土地としてでしょうか？」        ← 9分後
20:26 社長「収益」
20:31 小笠原「賃貸状況なにか資料ありますか？」
```

**着手できるまで21分・3往復。** これをAI秘書が依頼の直後に肩代わりします。

## 書き方のルール

- `## 依頼種別` … `src/lib/due-rules.ts` の `REQUEST_TYPES` と**同じ名前**にする
- `必須` 列に **★** … これが無いと着手できない項目。**社長に必ず聞く**
- `必須` 列が空 … 慣例で埋まる項目。**提案の形で聞き、「はい」で確定**する
- `既定の提案` が `-` … こちらで決めようがない項目（金額・氏名など）。質問になる
- `既定の提案` に `{期日}` … 標準納期から計算した日付に置き換わる
- **キー**は英数字。一度決めたら変えない（変えると確認中のタスクが繋がらなくなる）

## 自動補完ルール

**ある項目が決まると自動的に決まる項目**を書く。ここに書いた分は社長に聞き返さない。

「うちで買う」と答えた直後に「買主様のお名前は？」と聞くような、
**答えれば分かることを聞き返す**のを防ぐための表。

| 条件の項目 | 値に含まれる語 | 埋まる項目 | 入る値 |
|---|---|---|---|
| buyerType | 自社 | buyerName | 株式会社MD NEXT |
| buyerType | 買取 | buyerName | 株式会社MD NEXT |
| buyerType | 自社 | addressee | 売主様宛て |
| loan | 現金 | settlement | 契約から30日後（現金決済） |

## 購入申込書

| キー | 項目名 | 既定の提案 | 必須 |
|---|---|---|---|
| buyerType | 買主の立場（自社買取／一般のお客様／法人） | - | ★ |
| buyerName | 買主様のお名前・名義 | - | ★ |
| price | 購入金額（指値） | - | ★ |
| deposit | 手付金 | 売買代金の5% | |
| loan | 融資利用の有無 | 融資利用あり・ローン特約あり | |
| settlement | 決済（引渡）の希望時期 | 契約から45日後 | |
| addressee | 申込書の宛先 | 売主様宛て | |
| expiry | 申込の有効期限 | 発行日から7日間 | |

> 「これ買いたい」だけで飛んでくるのがこの種別。**自社買取なのかお客様の購入なのかで
> 書式も動き方も変わる**ため、buyerType を最優先で聞く。

## 査定書

| キー | 項目名 | 既定の提案 | 必須 |
|---|---|---|---|
| ownerName | 売主様のお名前 | - | ★ |
| basis | 査定の前提（更地／収益／実需） | - | ★ |
| purpose | 用途・提出先 | 売主様への提示用 | |
| range | 価格の出し方 | 上限・下限の幅で提示 | |

> Googleマップのリンクだけ・住所だけで飛んでくることが多い（55件）。
> 場所が分かっても**誰の物件か**が分からないと動けないので ownerName を必須にしている。
> basis は履歴の「土地としてでしょうか？」がそのまま項目になったもの。
