# 1. いま実際に動いていること

LINEグループ（MD NEXT秘書がいるグループ）で、下のように送ると自動で処理されます。
**すべて本番で稼働中**です。

## 1-1. タスクまわり

| やりたいこと | LINEでの送り方 | 秘書がやること |
|---|---|---|
| タスクを登録する | **普通に依頼を書くだけ**<br>例:「メロディハイム626の査定書お願いします」 | 発言を読んで「これは依頼だな」と判断したらNotionに起票し、`✅ タスク登録しました` と返す |
| 誰かに振る | 依頼文の中で **@メンション**<br>例:「@杉山 上野東の資料まとめて」 | メンションされた人を担当者としてNotionに保存（リマインド時に@通知が飛ぶ） |
| あとから担当者を決める | 登録済みメッセージに**引用リプライ**して @メンション | 担当者を後付け・変更する |
| タスクじゃなかった | 引用リプライで「**タスクじゃない**」「**取り消し**」「**削除**」 | Notionから消す（`🗑 タスクを取り消しました`） |
| 終わったと伝える | 引用リプライで「**完了**」「**終わりました**」「**済み**」「**done**」 | ステータスを「完了」にする（記録は残る） |
| まとめて終わったと伝える | 朝のリマインドの番号で返信<br>例:「**3済**」「**1,2完了**」「**4おわった**」 | 該当タスクを完了にし、`残り○件です` と返す |

**登録されない発言**（意図的にスキルとして入れてあります）
雑談・相槌・感想・質問だけの発言／「戻り12時半です」等の予定共有／出退勤の報告／ホワイトボード記載依頼。
→ Claudeが「タスクである確信度」を出し、**0.7未満は黙って無視**します。

## 1-2. 期日の自動決定

**期日は毎回同じルールで決まります**（AIの気分で変わらないよう、表で固定してあります）。

| 依頼の種類 | 標準納期 | 期限時刻 |
|---|---|---|
| 査定書 | 7日後 | 17:00 |
| 物件資料・相場資料・図面 | **当日**（18時以降の受信は翌日） | 18:00 |
| 業者・管理会社への確認 | 翌日 | 18:00 |
| 内見・現地調整 | 当日 | 18:00 |
| 重要事項説明書 | 5日後 ★暫定 | 17:00 |
| 売買契約書 | 5日後 ★暫定 | 17:00 |
| 書類取得（謄本・公課証明等） | 3日後 ★暫定 | 18:00 |
| その他 | 翌日 | 18:00 |

- メッセージに「**明日17時までに**」など明示があれば、**そちらが最優先**
- 「**急ぎ**」「**至急**」と書けば、種類に関係なく**当日**
- 返信には理由が出ます → `📅 期日：8月15日(金) 17:00` / `└ 査定書の標準納期（7日）で設定`
- 日数は**暦日**（土日祝を飛ばしません）

> ★暫定の3つ（重説・契約書・書類取得）は**実務の感覚に合わせて要調整**です。
> 決まれば設定ファイルの3行を直すだけで反映できます。

## 1-3. リマインド

| いつ | 内容 |
|---|---|
| **毎朝8時** | 期限超過・本日期限・明日期限を**番号付き**でグループに投稿。担当者には@通知 |
| **期限の1〜2時間前** | 「⏰ まもなく期限です（本日18:00まで）」を投稿。当日登録は1時間前、前から積んであるものは2時間前 |

朝のリマインドはこんな形です。

```
🔔 本日のリマインドです

⚠️ 期限超過（2件）
1. 上野東2丁目の公課証明取得（3日超過）@杉山
2. 業者への確認（1日超過）

【本日期限】
3. メロディハイム626の査定書（今日中）@有吉

【明日期限】
4. 内見の日程調整（今週中）

──────────
終わったものは番号で返信してください
例：「3済」「1,2完了」「4おわった」
```

## 1-4. 顧客登録（CRM連携）

紹介客をLINEから直接Notion CRMに登録できます。

```
#新規 山本太郎/ヤマモトタロウ/090-1234-5678/売主/査定依頼/上野東2丁目/杉山/田中様
```

区切りは `/`。**必須は氏名と連絡先だけ**、あとは空でOK（`#新規 山本太郎/090-1234-5678` でも通る）。
連絡先は電話でもメールでも、分からなければ「**不明**」「**メール**」「**LINE**」等の状況語でも登録できます。

秘書がやること:
- **重複チェック**（電話・メールを正規化して照合）→ 既存客なら新規作成せず、履歴に追記＋役割を追加
- 新規なら **CRM_顧客** に起票（区分・顧客ソース・登録経路・ステータス等を自動セット）
- **対応内容が書いてあれば CRM_案件 も自動作成**し、内容と立場から**フェーズを14段階で推定**
  （例: 売主＋査定依頼 →「【売】査定」／買主＋買付 →「【買】買付申込」）
- 活動履歴（CRM_活動）にLINE受信原文を記録

## 1-6. メール送信（2026-08-14 本番復活）

LINEで頼むと、**下書きを作って見せ → 人が「送信」と返事して初めて送る**方式です。

| やりたいこと | LINEでの送り方 | 秘書がやること |
|---|---|---|
| メールを出す | 「**山本さんにメール送っておいて。内覧の日程の件で**」 | 差出人・宛先・件名・本文・署名を組み立てて下書きを提示 |
| 送信する | 下書きに「**送信**」「**OK**」「**これでお願いします**」 | 実際に送信。**修正指示が混ざっていると送らず作り直す**（誤送信防止） |
| 直す | 「**もう少し丁寧に**」「**日程を3案入れて**」 | 作り直して再提示 |
| やめる | 「**キャンセル**」「**やめて**」 | 破棄 |
| 差出人を変える | 「**会社名義で**」「**下村名義で**」 | 差出人アカウントと署名を切り替え |

- 宛先は名前で指定できます（社内アドレス帳。「下村さん」「下村」どちらでも解決）
- 下書きは**30分で自動失効**します（古い下書きが新しいやり取りを横取りしない）

## 1-7. 画像・PDFの受け取り（2026-08-14 追加）

**これまでテキスト以外は捨てていました。** 受け取れるようになっています。

| 送ったもの | 秘書がやること |
|---|---|
| **名刺の写真・PDF** | メール下書きの宛先待ち中なら、**読み取って宛先（会社名・役職・氏名・メール）に設定** |
| **PDF（資料・見積など）** | 添付候補として保持。「**添付して**」で作成中のメールに添付 |
| 上記以外の文脈 | 黙って「直近のメディア」として保持（返信しない＝グループを荒らさない） |

> 💡 いまは**メールの文脈でしか中身を使っていません。**「図面を送ったら内容を読んで
> タスクにする」「見積を読んで原状回復判定に回す」等は**これからやること**（4章）。

# 2. 運用上の注意

- **画面のログイン（2026-08-14 有効化済み）**: `/` `/dashboard` `/restoration` を開くと
  **ログイン画面**（`/login`）に飛びます。ID・パスワードを入れると30日間は入りっぱなしになります。
  - 値は Vercel の `APP_BASIC_USER` / `APP_BASIC_PASSWORD`。sensitive指定のため画面から再表示できません。
    忘れたら同じ手順で**上書き登録＋再デプロイ**すればリセットできます。
  - パスワードを変えると、**既にログイン済みの人も全員ログインし直し**になります（Cookieが自動失効するため）。
  - 当初はBasic認証にしていましたが、**アプリ内ブラウザでログイン窓が出ず入れない**問題が出たため
    通常のログイン画面に変更しました。curl等からはBasic認証も引き続き使えます。
- **LINEのWebhookとCronは認証から除外**しています。ここに認証を掛けると秘書が無言で止まります。
- **デプロイはCLIから**行っています（`vercel deploy --prod`）。GitHubにpushしても本番は変わりません。
  この運用が原因で、過去にメール機能が本番から消えた事故が起きています（→ 4-3 D1）。

# 3. いま「できないこと」

営業事務にしていく上での壁を、正直に並べます。

| できないこと | 何が困るか |
|---|---|
| ~~画像・PDFを受け取れない~~ | ✅ 2026-08-14 解消（受け取れる） |
| ~~メールを出せない~~ | ✅ 2026-08-14 解消（本番復活） |
| **受け取ったPDF・画像の"中身"を業務に使えていない** | 今はメールの宛先・添付にしか使っていない。図面・見積・謄本を読んでタスク化・振り分けまでは行かない |
| **顧客・案件・タスクが繋がっていない** | タスクは「文字列」でしかなく、どの顧客・どの物件の話か機械が知らない。**営業事務化の最大の壁** |
| **過去を検索・集計できない** | 「山本様の件どうなってる？」に答えられない。週報も出せない |
| **LINE以外から入れられない** | メール・電話メモ・SUUMO反響は別系統のまま |
| **物件名の表記ゆれを吸収できない** | 「泉ヶ丘」「泉ケ丘」を別物として扱う |
| **人の名寄せができない** | 誰が誰かの対応表がない（LINEの表示名頼み） |
| **ダッシュボードが空** | 現状Notionを直接見るしかない（`/api/tasks` は500で壊れている） |

# 5. 下村さんにお願いしたい操作

## 画面のパスワードを設定する（D0）

パスワードは私からは設定しません（認証情報を扱わないため）。下記を実行してください。

```bash
cd ~/AI開発/apps/aisecretary && vercel env add APP_BASIC_USER production
```

続けてパスワードを登録します。

```bash
cd ~/AI開発/apps/aisecretary && vercel env add APP_BASIC_PASSWORD production
```

登録後、**再デプロイして初めて有効になります**。

```bash
cd ~/AI開発/apps/aisecretary && vercel deploy --prod
```

これで `/dashboard` `/restoration` はID・パスワードを聞かれるようになります。
LINEのWebhookとCronは除外してあるので、**秘書の動作には影響しません**。
