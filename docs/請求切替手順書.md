## 先に結論：停止のタイミングについて

**「切り替えで止まるかもしれないから夜にやる」という心配は不要です。**

| | 停止するか | 理由 |
|---|---|---|
| 第1部（支払い方法・クレジット購入） | **止まらない** | APIキーは変わらない。**むしろ復旧する** |
| 第2部（ワークスペース分離） | **2〜3分だけ止まる** | 新しいキーを発行してVercelに入れ直すため |

しかも **AI秘書は 8/19頃から既に止まっています**（残高切れ）。
第1部は「止める」のではなく「**動かす**」作業なので、**気づいたときにすぐで構いません。**

夜にやる意味があるのは第2部だけです。第2部は Claude 側の作業（Vercel環境変数の更新と再デプロイ）が
必要なので、**やるときに声をかけてください。第1部だけ先に済ませても問題ありません。**

## 第1部：会社カードへの切り替え（下村さんの操作・無停止）

`https://console.anthropic.com` → 左メニュー **Settings（設定）** → **Billing（請求）**

### ⚠️ 順番を守ってください

**① 請求先情報に会社名・住所を先に入れる**

Billing 内の **Billing details / 請求先情報** を編集し、以下を入力する。

- 会社名: 株式会社MD NEXT
- 住所: 会社所在地
- （登録番号の欄があれば会社のT番号）

> **これを先にやる理由**: 領収書は発行時点の請求先情報で作られます。
> カード登録や購入を先にやると、**個人名の領収書が出て経理で通りません。**
> 後から直しても、**発行済みの領収書は遡って直りません。**

**② 会社カードを追加してデフォルトに設定**

Payment methods → Add payment method → 会社カードを登録 → **Default（デフォルト）に設定**。
個人カードは、次の請求が会社カードで通るのを確認してから削除する。

**③ 未払い残高 $0.16 を清算**

**④ クレジットを購入**

- 推奨: **$20（約3,000円）**
- AI秘書の実測が月$2.5前後なので、**半年以上もちます**
- 少額から始めて、足りなければ足す方針で問題ありません

**⑤ 上限と通知を設定（← 今回の再発防止はここ）**

| 設定 | 推奨値 | 目的 |
|---|---|---|
| Monthly spend limit（月額上限） | **$30** | 暴走時の青天井を防ぐ |
| Auto-reload（自動リロード） | **ON**（残高$5を切ったら$20補充） | 残高切れで無言停止しなくなる |
| Email alerts（メール通知） | **ON** | 気づかないうちに止まるのを防ぐ |

> 今回の事故は「**残高が切れても誰にも通知されなかった**」ことが本質です。
> ④より⑤のほうが重要です。

**⑥ 使っていないAPIキーを削除**

API keys の画面で、以下の**4本を Delete**（作った覚えのある実験用のものです）。

- Automatic task
- The remaining items and estimation
- Create a narration for sleep.
- realestatemdnext

**残すのは2本だけ:**

| キー名 | 用途 | 扱い |
|---|---|---|
| **LINE Secretary** | AI秘書本体（`.env.local` / Vercel に設定済み） | **絶対に消さない** |
| **Seller report** | 用途未確認（$2.24／Opus 5／8月18〜19日に単発使用） | 心当たりが出るまで保留 |

> **削除前に必ず**「LINE Secretary」以外を消すことを確認してください。
> LINE Secretary を消すと AI秘書が完全停止し、再発行＋Vercel再設定が必要になります。

## 第2部：ワークスペースの分離（Claude と一緒に・2〜3分停止）

### なぜやるのか

今回、**「Seller report」が1日で$2.24使ったことで、AI秘書の残高まで巻き添えで尽きました。**
6本のキーが全部同じ Default ワークスペースにあるため、**誰かの一括処理が業務ツールを道連れにします。**

```
ワークスペース「業務」    ← LINE Secretary（月$10上限）
ワークスペース「開発・検証」← Seller report ほか（別枠）
```

分ければ、開発側で使い切っても**AI秘書は止まりません。**経費の仕分けも楽になります。

### 手順（この順で。順番を守れば停止は2〜3分）

1. **下村**: Console で Workspace「業務」を作成 → 月額上限 $10 を設定
2. **下村**: そのワークスペース内で**新しいAPIキーを発行**（名前: `LINE Secretary v2`）
3. **下村**: キー文字列を Claude に渡す **←【重要】下記の注意を読んでください**
4. **Claude**: Vercel の環境変数 `ANTHROPIC_API_KEY` を更新 → 再デプロイ（**ここで2〜3分停止**）
5. **Claude**: 動作確認（LINEにテスト依頼を投げてNotion登録を確認）
6. **下村**: 確認が取れてから**旧キー「LINE Secretary」を削除**

> **【重要】キーの渡し方について**
> APIキーは認証情報です。**このチャットに貼り付けると会話ログに残ります。**
> 安全なのは、**下村さんご自身が Vercel の管理画面で環境変数を直接書き換える**方法です。
> その場合、手順4は「Vercel → プロジェクト aisecretary → Settings → Environment Variables →
> `ANTHROPIC_API_KEY` を編集 → Save → Redeploy」になります。**この方法を推奨します。**
> Claude が代行する必要があるのは再デプロイ後の動作確認だけです。

### ⚠️ 手順6を飛ばさないこと

旧キーを先に消すと、**新キーの反映前に AI秘書が停止**します。
必ず「新キーで動いた」ことを確認してから消してください。

## 第3部：経理処理（ルールブック `4797cc98` 準拠）

| 項目 | 内容 |
|---|---|
| **勘定科目** | **支払手数料**（「少額費用の集約にも利用」に該当） |
| **保存場所** | 社内共有ドライブ |
| **ファイル名** | **`業者名_金額.pdf`** → 例: `Anthropic_3000円.pdf` |
| **保存期間** | 7年（税務署の指摘があれば10年） |
| **電子帳簿保存法** | 日付・金額・取引先で検索できる状態にする／訂正削除履歴を残す |

### 事前に済ませておくこと

- [ ] **会社カードで継続課金（固定費）を組むこと自体の社内承認**
      ← ルールブックに「金銭の入出金は必ず承認フローに基づく」とあるため。
      金額は1万円未満なので高額支出（1万円以上）の事前承認は不要。
- [ ] **顧問税理士へのインボイス確認**
      Anthropic は**海外事業者で適格請求書発行事業者番号がありません**。
      ルールブック上「インボイスに該当しない請求書は仕入税額控除が不可」となるため、
      **消費税の税区分（課税・非課税・不課税）の整理が必要**です。
      他の海外SaaSもまとめて相談するのが効率的です。

### 毎月やること

購入・課金のたびに Console から領収書PDFをダウンロードし、
`Anthropic_金額.pdf` の名前で共有ドライブに保存する。
